# Architecture

This page deliberately has the same path as the `architecture/` folder.

Opening **Wiki → architecture** renders this Markdown page. The folder remains expandable in the sidebar, so its child pages are still directly available.

## Page-first routing

When a wiki page and a derived folder share a path, the page wins. Folder listings are only shown when no page exists at that exact path.
