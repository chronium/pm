## Goal

Append a new wiki section under a specific heading or at the end of a page as a safer additive documentation workflow.

## Proposed implementation

- Add a wiki service method that appends a heading plus markdown content.
- Optionally place the section under an existing parent heading; otherwise append at the end of the body.
- Reject missing parent headings when one is requested.
- Expose through MCP as `append_wiki_section`.

## Acceptance criteria

- Appending at end works for existing pages.
- Appending under a heading keeps the new section in the intended part of the page.
- Empty heading/content and missing page cases fail predictably.
- Frontmatter remains internal and unchanged except for modified timestamp.

## Validation notes

- Add service and MCP tests for append-at-end, append-under-heading, missing heading, empty content, and escaping-safe output.
