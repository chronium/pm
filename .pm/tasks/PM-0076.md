Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Add the top-level activation trigger persistence model, including stable key, title, ordered task or milestone requirements, and an optional activation provenance record.

Acceptance criteria:
- Requirements use explicit task or milestone kinds and stable local sources.
- Activation modes are automatic, manual, or override.
- Override records can persist a reason and the exact waived-requirement snapshot.
- Actor identity is not persisted in v1; Git history provides authorship.
- YAML round-trip tests cover inactive, automatic, manual-only, and overridden triggers.

This task establishes storage shapes without implementing transitions.
