Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Implement the explicit redefine workflow for changing requirements on an active trigger.

Acceptance criteria:
- Preview affected milestones and currently eligible tasks before mutation.
- Replace the definition and clear the previous activation record as one bounded operation.
- Automatically create a new automatic record when the new requirements are already satisfied.
- Otherwise leave the trigger pending.
- Require confirmation when active milestones would become inactive.
- Failures restore the previous definition and activation provenance.
- CLI and application tests cover satisfied, pending, cancelled, and rollback paths.
