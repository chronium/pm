## Goal

Remove the project claiming path now that existing local projects have been claimed and new projects use authenticated registration directly.

## Proposed implementation

- Remove the top-level `claim` CLI command from command registration and global config.
- Remove or retire the legacy claim path in next-ID registration if it is no longer needed for supported projects.
- Update README/help text so project setup points at `init` and normal authenticated Worker registration.
- Keep existing `.pm/project_id.txt` behavior intact for already-claimed projects.

## Acceptance criteria

- `pm claim` is no longer exposed.
- Existing projects with `.pm/project_id.txt` continue allocating IDs.
- New projects still register correctly through the normal flow.
- Tests cover existing-project registration behavior after claim removal.

## Validation notes

- Run .NET build and tests.
- Smoke a task creation path in an already-claimed project.
