## Goal

Update metadata for multiple tasks in one call for import cleanup and batch organization.

## Proposed implementation

- Add a bulk metadata service method for fields such as track and milestone.
- Validate all task IDs and target metadata before mutation.
- Reuse existing single-task metadata patch behavior where practical.
- Move task order scopes when track or milestone changes.
- Expose through MCP as `bulk_update_task_metadata`.

## Acceptance criteria

- Valid batches update all requested tasks.
- Missing tasks, duplicate IDs, invalid tracks, or invalid milestones fail before partial mutation.
- Response reports requested, updated, and unchanged tasks.
- Existing single-task metadata update behavior remains unchanged.

## Validation notes

- Add service and MCP tests for track changes, milestone changes, mixed unchanged tasks, validation failures, and order scope updates.
