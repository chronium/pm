## Goal

Add `pm site build` to export a sanitized project snapshot and the embedded Angular application as a safe, self-contained static directory.

## Scope

- Add `--output <path>` with default `dist/pm-site` and `--force` replacement.
- Reject dangerous destinations: the project root, `.pm`, descendants of `.pm`, ancestors of the project, and existing symlinks.
- Validate the project and require embedded Angular assets.
- Build snapshot data through application services, including board/navigation, task details and dependencies, display settings, wiki summaries, and wiki bodies.
- Exclude local paths, identities, recovery and next-ID configuration, credentials, and machine-local metadata.
- Stage all output beside the destination and replace only after successful serialization and asset copying.
- Extend embedded Angular asset storage with safe enumeration/copy support.
- Generate static metadata in `index.html`, `<base href="./">`, `pm-snapshot.json`, and `.nojekyll`.
- Cover snapshot completeness, deterministic serialization, excluded data, missing assets, invalid projects, destination safety, atomic replacement, and force behavior with .NET tests.
