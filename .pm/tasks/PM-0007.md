## Implementation Plan

- Add wiki-mode search over wiki path, title, and markdown body.
- Render matches in the wiki content area or a focused wiki search results view.
- Preserve the wiki tree/sidebar and avoid storage format changes.
- Reuse existing wiki service, markdown rendering, templates, and htmx conventions.

## Acceptance Criteria

- Users can search wiki pages from the web wiki UI.
- Results include nested pages and expose enough page context to choose a match.
- No-results and invalid markdown cases render safely without breaking navigation.
- User-controlled wiki content and search terms remain escaped where appropriate.

## Validation Notes

- Test matching, no-results state, escaping, nested paths, and invalid wiki markdown behavior.
- Run the .NET build and test suite.
