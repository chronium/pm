## Goal

Promote task notes from MCP-only workflow to user-facing CLI and web workflows.

## Proposed implementation

- Add `pm task note <id> <text>` and optionally `--edit` for longer notes.
- Add a small Add note action/form in task detail view.
- Reuse `TaskService.AppendTaskNote`.
- Keep notes appended under the existing `## Notes` convention.

## Acceptance criteria

- CLI can append single-line and edited multi-line notes.
- Web can append a note without replacing the whole task body.
- Empty notes fail clearly.
- MCP `append_task_note` behavior remains unchanged.

## Validation notes

- Add command, endpoint, renderer, and service tests for note creation and validation failures.
- Run .NET build and tests.
