## Goal

Bring wiki search parity to web so users can search wiki pages from wiki mode.

## Proposed implementation

- Add a search form in wiki mode, likely in the wiki sidebar or wiki index header.
- Add a web route that uses `WikiService.SearchPages` and renders results in the wiki content area.
- Preserve the wiki tree/sidebar while viewing search results.
- Keep search query in the UI after submitting.

## Acceptance criteria

- Users can search wiki path, title, and body from the web UI.
- Results include title, path, snippet, and modified time.
- No-results and validation states are clear and escaped.
- Existing wiki index/detail/edit/create flows continue working.

## Validation notes

- Add endpoint and renderer tests for matches, no matches, escaping, and tree preservation.
- Run .NET build and tests.
