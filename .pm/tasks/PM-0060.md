## Goal

Bring the Angular task detail, create, and edit dialogs up to the visual and interaction quality of the surrounding task board while preserving their routed, keyboard-efficient workflows.

## Scope

- Refine dialog sizing, spacing, hierarchy, typography, metadata layout, action placement, and scroll containment for realistic task content.
- Keep task content more prominent than modal chrome, metadata, and secondary actions; avoid decorative cards, gradients, broad shadows, and excessive whitespace.
- Make read, edit, create, loading, error, empty-description, validation, pending, disabled, stale-conflict, and destructive-confirmation states cohesive.
- Improve the Markdown reader/editor transition, EasyMDE toolbar and sizing, focus behavior, keyboard flow, and responsive/mobile presentation.
- Preserve board context and filters behind the routed dialog, with correct focus trapping/restoration, Escape behavior, and unsaved-change protection.
- Integrate the track and milestone controls from PM-0029 without turning the dialog into a large settings panel.
- Reuse existing design tokens, buttons, form fields, confirmation dialog, Markdown components, and task-dialog primitives.
- Add focused component and Storybook coverage for default, long-content, editing, pending, error, conflict, disabled, and mobile states.
- Use Playwright for final keyboard, responsive, direct-link, and critical mutation smoke validation.

## Acceptance

- Task create, detail, and edit dialogs feel cohesive with the board and remain dense and readable at realistic content lengths.
- Primary actions and task content are visually obvious; secondary metadata and destructive controls remain contextual.
- Long content and the editor scroll internally without moving the board or producing accidental horizontal overflow.
- Keyboard navigation, focus trapping/restoration, visible focus, Escape behavior, and mobile layouts remain accessible.
- Existing create, direct-link, edit, state-change, conflict, remove, filter-preservation, and dirty-navigation behavior remains intact.
- Relevant Angular unit tests, Storybook tests, strict and production builds, and desktop/mobile browser smoke checks pass.

## Out of scope

- Backend task API changes, new task metadata fields, full-page task routes, and broad task-board restyling.
