## Goal

Produce the small Linux OCI runtime that executes released PM commands inside the reusable GitHub Action.

## Implement

- Build from a minimal Alpine-compatible base when supported by the released .NET artifact.
- Include the published PM executable, embedded Angular assets, certificates, and runtime dependencies required by `doctor`, `site-build`, and `version`.
- Keep build inputs deterministic and avoid development SDKs, source trees, package caches, and unrelated tools in the final image.
- Provide an image entrypoint suitable for GitHub's container Action runtime and mounted `/github/workspace`.
- Label the image with source and PM version metadata.
- Add local container smoke coverage for version reporting, project validation, and static export.
- Produce an immutable image digest suitable for pinning from `action.yml`.

## Acceptance criteria

- The image runs each supported PM command against a mounted disposable project.
- Static output created beneath the workspace remains available on the host.
- Missing files, invalid projects, and read-only inputs fail with useful PM diagnostics.
- The final runtime contains no build credentials or unnecessary development tooling.
- Automated checks report image identity and exercise the exact published layout.
