## Goal

Provide complete current task create/read/edit/state/remove workflows through routable Angular dialogs.

## Implementation

- Add `/tasks/new` and `/tasks/:taskId` child routes under the mounted task board; order routes so `new` is not treated as an ID.
- Render task detail as a native modal dialog over the board. Direct navigation or refresh restores the board and opens the requested dialog; closing navigates back to `/tasks` while preserving filters.
- Keep a future full-page task route out of scope.
- Build read mode around rendered Markdown and compact metadata/actions.
- Build edit mode with Angular 22 Signal Forms for title, status, priority, and description.
- Wrap EasyMDE in one local standalone signal-compatible Markdown editor component that owns initialization, cleanup, focus, disabled state, and value synchronization.
- Render Markdown with marked and sanitize every preview/read result with DOMPurify; never bypass Angular HTML security.
- Apply task ETags to edit, state change, and remove requests.
- Preserve destructive confirmation, pending/disabled states, field/server validation, focus trapping/restoration, Escape behavior, and scroll containment.

## Acceptance

- Create, open, direct-link, edit, cancel, state change, conflict, and remove flows work with keyboard and pointer input.
- Long task content and the editor scroll internally rather than scrolling the board.
- Dialog routes preserve current board filters.
- Unit/component tests and Playwright cover critical workflows.
