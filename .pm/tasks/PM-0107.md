## Goal

Resolve the frozen YAML contract into one atomic transport-neutral Overview document for current and linked projects.

## Implement

- Add the closed ready composition union for single and split layouts plus hero, milestone, tasks, wiki, Markdown, and copyright section records.
- Return disabled, ready, or invalid atomically; never return a partially resolved composition.
- Reuse milestone lifecycle and priority ordering, BoardService task order and task-query predicates, wiki parsing, sanitized Markdown provenance, and linked-project read contexts.
- Select the highest-priority active milestone with configured milestone order as the tie-breaker unless an explicit milestone is configured.
- Resolve region order exactly, keep valid empty sections, and calculate a revision from every effective input without reacting to unrelated project changes.
- Keep all file reads and selection logic in the application service rather than API or Angular code.

## Acceptance

Tests cover implicit and explicit single layouts, split regions, repeated content sections, copyright, empty content, invalid configuration, automatic and explicit milestones, task filtering/order/limits, wiki and Markdown selection, linked-project isolation, and stable revisions. Run the .NET build and test gates.
