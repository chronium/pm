## Goal

Make Angular formatting deterministic and mandatory before task commits.

## Implementation

- Add explicit Prettier write and check scripts to the Angular workspace.
- Exclude generated API contracts and generated/build output from formatting.
- Format the existing handwritten Angular source and workspace configuration.
- Update AGENTS.md so Angular tasks run formatting before validation and commit.
- Document the formatter commands with the other Angular workspace commands.

## Validation

- `npm run format`
- `npm run format:check`
- `npm run check`
- `npm test`
- `npm run test:storybook`
- `npm run build`
