## Goal

Preserve family navigation in read-only static publishing without requiring an initial bundled multi-project export.

## Proposed implementation

- Add optional public site URLs to project link declarations.
- Render parent, child, and sibling navigation to separately published sites.
- Translate canonical cross-project wiki and task links when a public target is known.
- Render a clear unavailable target when no public URL exists.
- Keep single-project static generation functional with no linked checkout present.

## Acceptance criteria

- Each project can publish independently.
- Cross-project links use public URLs rather than local paths.
- Static generation succeeds with missing family projects.
- Bundled family publishing remains possible as a later extension.
