## Goal

Correct the public external Action smoke so reusable workflow calls test the committed consumer fixture rather than the caller repository, then publish the correction as PM 1.0.4 without rewriting the immutable 1.0.3 release.

## Implement

- Update `chronium/pm-action-smoke` so its reusable workflow explicitly checks out the public smoke repository fixture at an immutable revision.
- Validate `version`, `doctor`, and `site-build` against the committed fixture when invoked from another repository.
- Pin PM's release workflow to the corrected signed public smoke revision.
- Preserve the existing immutable `v1.0.3` Action ref and OCI image.
- Publish the correction through the normal task patch transition as `1.0.4`.
- Advance `latest` only after the immutable `v1.0.4` external smoke succeeds; do not move `v1` for this task release.

## Acceptance criteria

- The public reusable smoke no longer relies on the caller repository containing `fixture/`.
- A manual external smoke against `v1.0.3` passes all supported commands before PM adopts the corrected smoke revision.
- The PM workflow pins an immutable, GitHub-verified signed smoke-repository commit.
- The 1.0.4 candidate, promotion preflight, immutable smoke, and latest smoke all pass.
- `v1.0.3` remains unchanged, and release retries remain idempotent.
