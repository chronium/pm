## Goal

Unassign one or more tasks from a milestone without deleting the tasks.

## Proposed implementation

- Add a service method that clears `Milestone` for one or more task IDs.
- Validate all task IDs before mutation and reject duplicates.
- Update task modified timestamps for changed tasks.
- Keep task order scopes consistent when tasks move from a milestone scope to the unassigned scope.
- Expose through MCP as `remove_task_from_milestone`.

## Acceptance criteria

- Tasks assigned to a milestone become unassigned.
- Tasks already unassigned are treated as unchanged but valid.
- Missing tasks or duplicate IDs fail predictably.
- Existing bulk milestone assignment behavior remains unchanged.

## Validation notes

- Add service and MCP tests for mixed assigned/unassigned inputs, missing task failures, and order scope movement.
