## Goal

Move multiple tasks to one target state in a single call for imported plans, cleanup passes, and closing batches.

## Proposed implementation

- Add a bulk move service method that validates all task IDs and the target state before mutating.
- Move each task with the same state-ref behavior as single-task move.
- Preserve task order bookkeeping when tasks leave their old state scopes and enter the target scope.
- Expose through MCP as `bulk_move_tasks`.

## Acceptance criteria

- Valid batches move all requested tasks.
- Invalid state, missing task, duplicate IDs, or empty input fail before partial mutation.
- Response reports requested and moved task IDs.
- Existing single-task move behavior remains unchanged.

## Validation notes

- Add service and MCP tests for successful batch move, validation failures, duplicate IDs, and task order updates.
