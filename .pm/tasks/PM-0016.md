## Priority

Top priority for agent workflow.

## Goal

Apply narrow edits to an existing wiki page without replacing the full markdown file.

## Proposed implementation

- Define a small patch operation model for safe wiki body edits.
- Support initial operations such as replace section by heading, append after heading, and textual replace with expected old text.
- Preserve frontmatter metadata and update `ModifiedAt` only after a successful body change.
- Expose through MCP as `patch_wiki_page` with structured operation input.

## Acceptance criteria

- Agents can patch a section without sending the whole page body.
- Ambiguous or missing patch targets fail without mutation.
- Invalid paths and invalid operation payloads return stable errors.
- Existing full-page wiki update remains available.

## Validation notes

- Add service and MCP tests for section replacement, append-after-heading, textual replacement, ambiguous headings, missing targets, and unchanged patches.
