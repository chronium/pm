## Goal

Allow trusted MCP clients to preview, deliver, and reopen milestones in a selected write-trusted linked project with authoritative provenance and revision guards.

## Scope

- Add an optional `project` selector to `preview_milestone_delivery`, `deliver_milestone`, and `reopen_milestone`.
- Resolve assigned tasks, completion counts, lifecycle, activation gates, and exceptional-delivery snapshots exclusively within the selected project.
- Bind preview revisions to the selected project and reject cross-project or stale preview reuse.
- Preserve explicit exceptional-delivery confirmation and record the selected project's unfinished task IDs and reason.
- Reopen only the selected milestone, retain the normal delivery-precedence rules, and return any target-local activation impact.
- Return receipts with the target project ID and paths relative to that repository, followed by an authoritative target switchboard reread.
- Require linked-project write trust before preview-backed mutations; previews require only readable project access.
- Keep delivery and reopening unavailable to run-worker profiles.
- Remove active-project-only delivery adapters superseded by the selected-project path.

## Acceptance criteria

- Preview, ordinary delivery, exceptional delivery, and reopening work by alias, stable ID, and `parent`.
- A preview revision from one project cannot authorize delivery in another.
- Exceptional delivery snapshots cannot include tasks from another family member with the same ID.
- Delivery and reopening affect recommendation eligibility only in the selected project.
- Untrusted, unavailable, ambiguous, and stale targets fail before writing.
- Mutation receipts agree with immediate selected-project rereads and preserve delivery provenance.
- Focused service and stdio MCP tests cover ordinary and exceptional flows, stale/cross-project revisions, trust denial, duplicate IDs, recommendation impact, receipts, and run-worker denial.

## Out of scope

Angular controls remain tracked by PM-0099; this task concerns trusted MCP cross-project operations.
