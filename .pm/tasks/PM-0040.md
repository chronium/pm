## Goal

Create the root `web/` Angular workspace that will host the replacement PM web UI.

## Implementation

- Create Angular project `pm-web` on Angular 22 using standalone components, strict TypeScript/template checks, routing, zoneless change detection, plain CSS, and Vitest.
- Follow the current Angular naming/style guide: concise file names such as `app.ts`, `task-row.ts`, `inject()`, signal inputs/outputs, and no NgModules.
- Do not enable SSR or prerendering; PM is a local client-side application served by Kestrel.
- Add scripts for start, production build, unit tests, and type/build verification.
- Add a development proxy that sends `/api` to `http://127.0.0.1:51237`.
- Install and lock browser dependencies through Socket: EasyMDE, marked, DOMPurify, and Oat. Bundle them locally; do not use CDN assets in Angular.
- Ignore `node_modules/`, Angular caches, coverage, Storybook output, and `dist/`.
- Keep normal .NET build/test independent of Node; frontend build integration belongs to the release/cutover tasks.

## Acceptance

- `npm start`, `npm test`, and `npm run build` work from `web/`.
- The starter app is zoneless, strictly typed, routed, and contains no Material dependency.
- Dependency-changing commands are performed with `socket npm`.
- Repository documentation records the Angular development prerequisites and commands.
