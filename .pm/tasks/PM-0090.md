Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Expose structured milestone and activation workflows through the hosted JSON API and generated OpenAPI contract.

Acceptance criteria:
- Settings and read endpoints return descriptions, lifecycle, requirements, provenance, consumers, and impact data.
- Definition, activation, override, reset, delivery, reopening, redefine, and reconcile endpoints enforce revision preconditions.
- API responses use established problem details and refreshed resource revisions.
- Static snapshot contracts include resolved read-only activation state without mutation endpoints.
- Generated Angular API types remain reproducible.
- API, revision, OpenAPI, and static snapshot tests cover the new contracts.
