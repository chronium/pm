## Goal

Resolve declared projects safely across the expected submodule layout and independent local checkouts.

## Proposed implementation

- Maintain a private user-config registry from stable project IDs to checkout roots.
- Register a project when PM opens it successfully.
- Resolve the active project, verified relative path hints, then verified registry bindings.
- Verify every candidate through its .pm/project_id.txt before exposing it.
- Detect missing paths, identity mismatches, stale bindings, and uninitialized Git submodules.
- Produce a safely quoted git submodule update --init -- <path> suggestion without executing it.

## Acceptance criteria

- Relative submodule layouts work without per-machine setup.
- Independent clones resolve through local bindings.
- Absolute paths are never committed.
- Stale or malicious path hints cannot resolve as the wrong project.
- Missing links do not affect ordinary active-project commands.
