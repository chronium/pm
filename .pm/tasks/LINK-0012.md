## Goal

Let remote agents consult explicitly selected family wiki context while keeping the primary run repository authoritative and writable.

## Proposed implementation

- Extend run preflight with selected linked context projects and exact commits.
- Require every linked repository to be published, allowlisted by the runner, and available at the captured commit.
- Clone linked repositories into isolated read-only runtime locations.
- Expose linked PM wiki reads through the run-worker MCP while keeping all linked mutations disabled.
- Fail preflight for required context and warn for optional unavailable context.
- Record linked context revisions in the immutable run specification and report.

## Acceptance criteria

- Agents can search and read selected sibling wiki pages.
- Linked repositories receive no write credentials or writable mounts.
- Results identify exact context revisions.
- Missing context behavior is explicit and reconnect-safe.
