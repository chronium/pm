## Implementation Plan

- Add a text search control to the task board using the existing server-rendered filter and htmx patterns.
- Search task ID, title, and description preview/body.
- Combine search with existing track, milestone, and status filters without dropping current board context.
- Keep escaping and URL/query preservation centralized in existing renderer helpers.

## Acceptance Criteria

- Users can search tasks from the web board without a full-page workflow change.
- Search results respect the active track, milestone, and status filters.
- Empty search results render a clear empty state.
- User-controlled search text and matching content are escaped safely.

## Validation Notes

- Add focused tests for board rendering, query preservation, escaping, empty results, and combined filters.
- Run the .NET build and test suite.
