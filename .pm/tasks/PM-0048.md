## Goal

Provide an isolated component workshop for developing and validating the Linear-inspired design system.

## Implementation

- Add Storybook 10.5 with the Angular Vite framework selected for Angular 22. Keep Storybook zoneless and Compodoc disabled.
- Perform all dependency-changing setup through Socket.
- Load PM global tokens and Oat CSS in Storybook and provide toolbar switching for light/dark themes and representative viewport sizes.
- Add the Storybook accessibility and Vitest addons with headless Playwright Chromium checks; keep Angular Vitest as the primary unit runner.
- Start with stories for the reusable primitives that currently exist: buttons, badges, form fields, loading/empty/error states, destructive confirmation, and a foundation gallery. Add task rows/state groups, Markdown wrappers, and wiki tree nodes when those components exist.
- Model important variants: default, hover/focus where representable, selected, disabled, loading, validation error, destructive confirmation, long text, and dense data.
- Do not add Chromatic, publish Storybook, or create stories for every routed container/store.

## Acceptance

- Storybook starts and builds locally.
- Initial stories use realistic PM fixture data, representative viewports, and explicit light and dark foundation galleries.
- Accessibility violations configured as errors fail Storybook checks.
- Interaction stories cover meaningful component behavior without duplicating end-to-end tests.
