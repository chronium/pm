## Goal

Release the GitHub Action and its OCI runtime as one verifiable, promotable unit.

## Implement

- Build and test the Action runtime through the repository release workflow.
- Publish immutable OCI versions and record their digests.
- Generate or update Action metadata so each released ref selects the tested immutable image digest.
- Publish immutable semantic refs, a compatible moving major ref, and a moving `latest` ref for coordinated dogfood repositories.
- Prevent promotion when Action integration tests, container smoke tests, PM validation, or static export smoke tests fail.
- Document stable-consumer pinning and the intentionally floating `@latest` tradeoff.
- Emit sufficient release metadata to identify the Action commit, PM version, and OCI digest used by a run.

## Acceptance criteria

- An immutable Action release cannot drift to a different container image.
- `@v1` advances only within its documented compatibility contract.
- `@latest` selects the newest successfully promoted release rather than an unvalidated branch state.
- Consumers can recover the exact PM version and image digest from logs or outputs.
- A disposable external workflow successfully runs every supported command from published refs.
