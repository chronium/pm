## Goal

Release each PM version and its GitHub Action OCI runtime as one verifiable unit, with task-level edge promotion and milestone-backed stable promotion.

## Implement

- Consume the authoritative version and transition evidence established by PM-0124 and PM-0125.
- Build and test the Action runtime through the repository release workflow.
- Publish an immutable Action ref and OCI version for each successfully promoted `vMAJOR.MINOR.PATCH` release, and record the immutable image digest.
- Generate or update Action metadata so every released ref selects its tested OCI digest without creating an unsigned generated commit.
- Move `latest` only after a completed-task patch release passes the complete release and external Action smoke gates.
- Move `vMAJOR` only after a milestone delivery increments minor, resets patch, and the resulting release passes those same gates.
- Never move an immutable version ref and never infer or automatically increment major.
- Keep release-promotion and digest-pinning commits version-neutral.
- Document `@latest` as the coordinated edge channel, `@v1` as the latest fully delivered v1 milestone, immutable version refs for reproducibility, and commit SHAs for the strongest pin.
- Emit enough release metadata to identify the version transition kind, Action commit, PM version, and OCI digest used by a run.

## Acceptance criteria

- An immutable Action release cannot drift to a different commit or container image.
- A successful task release can move `@latest` without moving `@v1`.
- A successfully validated milestone delivery moves both `@latest` and the matching stable major ref to its new minor-zero release.
- Failed builds, tests, publication, external smoke checks, or version evidence never move a channel.
- Promotion retries are idempotent and cannot recreate or retarget an immutable version.
- Consumers can recover the exact PM version, transition kind, Action revision, and image digest from release evidence.
- Disposable external workflows successfully run every supported command from immutable, stable-major, and latest refs.
