## Goal

Bring web task metadata closer to MCP/CLI parity by allowing track and milestone edits in the task edit dialog.

## Proposed implementation

- Extend the structured task edit mode to include track and milestone controls.
- Use modeled service behavior so changing track/milestone updates task order scopes consistently.
- Preserve existing title/status/body editing behavior.
- Keep the dialog compact and avoid turning it into a large settings panel.

## Acceptance criteria

- Web task edit can change title, status, track, milestone, and body.
- Track/milestone controls are escaped, labelled, and keyboard accessible.
- Invalid/stale metadata rerenders useful errors without losing entered values.
- Existing task state and body save behavior remains unchanged.

## Validation notes

- Add service/endpoint/renderer tests for track and milestone edits, stale values, and board refresh behavior.
- Run .NET build and tests.
