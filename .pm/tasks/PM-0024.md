## Goal

Expose existing project validation outside MCP so users can inspect project health from the CLI.

## Proposed implementation

- Add `pm doctor` or equivalent top-level CLI command.
- Use `ProjectValidationService.ValidateProject`.
- Print grouped issues with severity, code, message, and relevant path/task/wiki/state metadata.
- Exit `0` when valid and non-zero when validation issues exist.

## Acceptance criteria

- Valid projects print a concise success message.
- Invalid projects print actionable grouped issues.
- Missing project returns the existing missing-project style failure.
- MCP `validate_project` behavior remains unchanged.

## Validation notes

- Add command tests for valid project, invalid project, and missing project.
- Run .NET build and tests.
