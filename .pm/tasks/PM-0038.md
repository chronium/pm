## Goal

Create CLI and web analogs for the planned `list_orphaned_items` MCP workflow.

## Proposed implementation

- Build on the repair-oriented orphan listing service once it exists.
- Add CLI command, likely under `pm doctor --orphans` or `pm orphans`.
- Add a web settings/project health section for orphaned items.
- Keep the feature read-only; repairs remain explicit separate actions.

## Acceptance criteria

- CLI, web, and MCP report the same orphaned item categories.
- Empty state is clear and quiet.
- Results include type, path, affected object, and suggested repair direction.
- `validate_project` remains the broader health check.

## Validation notes

- Add command, endpoint, renderer, and service tests with broken refs, stale task order, invalid wiki markdown, and unknown metadata references.
- Run .NET build and tests.
