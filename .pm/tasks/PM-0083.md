Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Implement explicit trigger activation transitions and their CLI surface.

Acceptance criteria:
- Manual-only triggers create manual activation records.
- Triggers with unmet requirements require an override reason and persist the exact waived requirements.
- Satisfied-but-unlatched triggers direct callers to reconciliation instead of manual activation.
- Reset is allowed only for active triggers whose current requirements are not satisfied.
- Existing activation provenance is never silently normalized when requirements later become satisfied.
- Mutation results return refreshed resolved trigger state.
- Tests cover every contextual action and invalid transition.
