## Priority

Top priority for agent workflow.

## Goal

Provide full-text task search so agents can find prior decisions, related work, and imported plans without reading `.pm` files directly.

## Proposed implementation

- Add task search across task ID, title, description, full markdown, track, milestone, and current state.
- Return structured results with task metadata, state, file path, match count, and a short escaped snippet.
- Support a reasonable limit parameter with clamping.
- Keep matching case-insensitive and deterministic.

## Acceptance criteria

- Search finds matches in metadata and body content.
- Results include enough context for an agent to choose a task.
- Blank queries return a stable validation error.
- Invalid task markdown is reported consistently.

## Validation notes

- Add service and MCP tests for metadata matches, body matches, snippets, limits, escaping, and invalid query handling.
