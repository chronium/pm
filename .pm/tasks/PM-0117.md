## Goal

Freeze the supported public contract for invoking Project Model from GitHub Actions before implementing its container wrapper.

## Design

- Define the root `chronium/pm@<ref>` Action identity and typed inputs shared by every command.
- Support the initial command allowlist: `doctor`, `site-build`, and `version`.
- Define command-specific inputs and outputs, including project path, site output path, base path, and reported PM version.
- Require project and output paths to resolve within `GITHUB_WORKSPACE`.
- Specify exit-code behavior, logging, summaries, and failure presentation for validation errors.
- Define `latest`, compatible-major, immutable-version, and SHA consumption guidance.
- Require released Action metadata to select a tested immutable OCI image digest.
- Keep artifact upload and hosting deployment outside the Action.
- Explicitly reject arbitrary shell evaluation, unrestricted CLI arguments, mutation commands, and repository write-back in v1.

## Acceptance criteria

- The contract is documented in the repository and expressed as an Action metadata proposal.
- Every initial command has unambiguous inputs, outputs, side effects, and exit behavior.
- Version/ref behavior distinguishes coordinated `@latest` consumers from stable third-party consumption.
- The design explains how the Action and OCI runtime are promoted as one tested release.
- Follow-up implementation tasks can proceed without inventing additional public semantics.
