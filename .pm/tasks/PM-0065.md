## Goal

Publish this repository's generated PM snapshot through the official GitHub Pages artifact deployment flow and mirror identical contents to an orphaned gh-pages branch.

## Scope

- Add a workflow triggered by default-branch pushes and manual dispatch with deployment concurrency.
- Build and validate using Socket-protected npm commands and existing .NET release conventions.
- Generate the static site from this repository's `.pm` project.
- Force-update an orphaned `gh-pages` branch for inspection.
- Upload the exact same directory with `actions/upload-pages-artifact` and deploy with official Pages actions.
- Pin every action to a reviewed full commit SHA.
- Use only `GITHUB_TOKEN`; do not add a PAT or third-party deployment action.
- Document that repository Pages source must be configured as GitHub Actions and verify the branch tree matches the artifact input.
