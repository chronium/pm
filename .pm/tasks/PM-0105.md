## Goal

Ensure an ordinary milestone delivery never persists a whitespace-bearing empty `reason` scalar.

## Scope

- Reproduce ordinary delivery through the application service and assert the persisted project YAML is clean under `git diff --check` semantics.
- Serialize an absent ordinary-delivery reason as omitted or an explicit YAML null without trailing whitespace.
- Preserve exceptional delivery reasons and existing configuration compatibility.
- Rebuild the release artifact and repeat the disposable milestone-delivery replay.
- Refresh and smoke-test the temporary Linux tarball from the fixed commit.

## Acceptance criteria

- Ordinary delivery produces no `reason: ` line.
- Exceptional delivery retains its trimmed non-empty reason.
- Focused regression tests, the .NET build/test gates, the release gate, and disposable replay pass.
- A refreshed native Linux tarball passes CLI, embedded web, and MCP smoke checks.
