## Goal

Demonstrate how current delivery status and selected work fit the Overview composition.

## Prototype

- Render automatic and explicitly selected milestone variants with title, description, lifecycle, task completion, and progress.
- Render filtered task sections using existing query semantics, project ordering, configurable title, and limit.
- Cover active, ready-to-deliver, inactive, delivered, empty, and invalid-reference fixture states.
- Keep task content prominent while avoiding a duplicate full task board.
- Preserve accessible status meaning without relying on color alone.

## Deliverable

Reviewable milestone and task-section prototypes integrated with the approved Overview shell.
