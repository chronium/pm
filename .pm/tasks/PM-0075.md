Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Replace the fragmented milestone title and priority representation with an ordered structured milestone definition containing title, Markdown description, priority, required activation trigger keys, and an optional delivery record.

Acceptance criteria:
- Existing scalar milestone configuration and milestone priorities remain readable.
- Structured definitions round-trip without losing dictionary order.
- Existing milestones migrate with empty descriptions, no required triggers, and no delivery record.
- New mutations write one canonical structured representation.
- Focused serialization, compatibility, and configuration revision tests cover the migration boundary.

This task defines persistence only; it does not resolve activation or expose new adapters.
