## Goal

Remove the NU1510 restore/build warnings caused by direct package references already supplied by `Microsoft.AspNetCore.App`.

## Proposed implementation

- Verify that `Microsoft.Extensions.DependencyInjection` and `Microsoft.Extensions.Http` are available through the existing framework reference.
- Remove the redundant direct package references from `PM/PM.csproj`.
- Restore dependencies so generated NuGet state reflects the project change.
- Build and test the full .NET solution, paying particular attention to dependency injection, HTTP client registration, MCP hosting, and web hosting behavior.
- Confirm that the NU1510 warnings no longer appear and that no package downgrade or version-conflict warnings replace them.

## Acceptance criteria

- `PM/PM.csproj` no longer directly references packages already supplied by `Microsoft.AspNetCore.App`.
- The solution restores, builds, and tests successfully.
- NU1510 is no longer emitted for `Microsoft.Extensions.DependencyInjection` or `Microsoft.Extensions.Http`.
- DI and HTTP-dependent application paths remain covered and functional.
