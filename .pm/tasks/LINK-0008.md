## Goal

Let tasks depend on tasks in another family project and incorporate those dependencies into next-task recommendations.

## Proposed implementation

- Resolve structured cross-project task dependencies through read federation.
- Treat unavailable dependencies as blocked with a visible warning.
- Keep state transitions unrestricted.
- Add family-wide next-task ranking by readiness, task priority, milestone priority, active-project preference, parent child order, local milestone order, and local task order.
- Detect cross-project dependency cycles among available projects and warn when the graph is incomplete.

## Acceptance criteria

- Ready, waiting, missing, and unavailable dependencies are distinguished.
- Current-project ranking remains deterministic.
- Family ranking prefers the active project for otherwise equal tasks.
- Unavailable projects never invalidate local task parsing or state changes.
