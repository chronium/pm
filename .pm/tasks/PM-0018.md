## Priority

Top priority for agent workflow.

## Goal

Show recent PM mutations so agents and users can audit what changed without scanning git or all `.pm` files.

## Proposed implementation

- Introduce an append-only mutation log for PM operations that change tasks, wiki pages, project config, or task order.
- Record timestamp, operation name, target type, target ID/path/key, and concise summary.
- Add a service query for recent entries with a limit parameter.
- Expose through MCP as `list_recent_changes`.

## Acceptance criteria

- Recent task creates, moves, markdown updates, wiki edits, renames, deletes, and config changes are listed.
- Results are ordered newest first.
- Missing log returns an empty list.
- Logging failures should not corrupt the primary mutation.

## Validation notes

- Add tests around log writes for representative mutations and recent-change query ordering/limits.
