## Goal

Let agents ensure a source-of-truth wiki page exists without first branching between create and update logic.

## Proposed implementation

- Add an idempotent wiki service method that creates a page if missing or updates title/body if it exists.
- Preserve created timestamp for existing pages and refresh modified timestamp only when content changes.
- Return whether the page was created, updated, or unchanged.
- Expose through MCP as `create_or_update_wiki_page`.

## Acceptance criteria

- Missing page is created.
- Existing page is updated without changing its path or created timestamp.
- Same title/body returns unchanged.
- Invalid path or title returns stable validation errors.

## Validation notes

- Add service and MCP tests for create, update, unchanged, invalid path, and missing title cases.
