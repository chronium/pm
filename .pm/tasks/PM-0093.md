Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Integrate deliverable descriptions and activation state into the task board and next-task workflow without hiding inactive work.

Acceptance criteria:
- Milestone headers show lifecycle and unmet gates with an expandable Markdown description.
- Task presentation distinguishes dependency readiness from activation eligibility.
- Sidebar counts preserve total work while making active work understandable.
- Next-task no-result feedback explains activation exclusions.
- Delivered milestones with accepted unfinished tasks remain visible but recommendation-ineligible.
- Responsive, keyboard, reduced-motion, static-mode, and error states follow existing UI principles.
- Add focused board and task workspace tests.
