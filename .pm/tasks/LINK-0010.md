## Goal

Make sibling project knowledge usable for compatibility work without copying wiki content between repositories.

## Proposed implementation

- Resolve canonical cross-project wiki links in rendered Markdown.
- Support explicit linked-project wiki search and navigation.
- Preserve breadcrumbs and project ownership when following links.
- Show unavailable targets with a non-destructive recovery message.
- Add link creation support to the Markdown editor without embedding local filesystem paths.

## Acceptance criteria

- Royale can navigate to a second-game wiki page and back through the family context.
- Broken or unavailable links do not break page rendering.
- Project IDs remain canonical while local aliases remain readable.
- Sanitization and static read-only rendering remain safe.
