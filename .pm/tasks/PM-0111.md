## Goal

Carry the resolved Overview document through static publishing and make enabled exports Overview-first.

## Implement

- Advance the static snapshot schema from 5 to 6 and include the resolved current-project Overview document.
- Fail `pm site build` for enabled invalid Overview configuration before replacing existing output.
- Preserve successful Tasks-first exports for disabled or absent sites.
- Adapt static `GET /api/v1/overview` reads through the existing interceptor and validation boundary.
- After snapshot loading, route an enabled empty hash root to Overview and a disabled root to Tasks.
- Preserve direct Tasks and Wiki deep links and redirect mutation-only or disabled Overview routes safely.
- Keep one resolved model; do not re-run configuration selection in Angular or the exporter.

## Acceptance

.NET snapshot/export tests and Angular static tests cover schema validation, ready and disabled documents, invalid publish failure, root selection, deep links, responsive Overview rendering, and previously published output preservation.
