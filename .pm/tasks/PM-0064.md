## Goal

Run the Angular task board and wiki directly from a generated static snapshot with hash routing and no backend.

## Scope

- Detect static mode from generated document metadata and configure hash location routing.
- Load and validate `pm-snapshot.json` once, then adapt it to existing project, board, task-detail, settings-display, wiki-index, and wiki-page GET contracts.
- Filter track, milestone, and status locally while preserving board order and query parameters.
- Disable polling and external-change handling in static mode.
- Hide v1 task/wiki search and every mutation affordance, including creation, editing, state changes, removal, wiki metadata, and settings.
- Redirect mutation-only routes to corresponding read views.
- Preserve task dialog/full-page views, dependencies, filters, wiki folders and breadcrumbs, Markdown, theme, and responsive behavior.
- Show quiet read-only snapshot context and generation time in the top bar.
- Surface clear errors for missing, malformed, or unsupported snapshots.
- Add Angular unit coverage and static Playwright smoke coverage for navigation, filtering, deep links, nested wiki content, responsive layouts, and zero backend/non-loopback requests.
