## Goal

Create CLI and web analogs for the planned `search_tasks` MCP workflow.

## Proposed implementation

- After task search service exists, add `pm task search <query> [--limit]`.
- Add web task-board search that combines with existing track/milestone/status filters.
- Use the same search service as MCP.
- Render task ID, title, state, track, milestone, and snippet.

## Acceptance criteria

- CLI, web, and MCP return consistent matches for the same query.
- Web search preserves current board filter context.
- Blank queries and no-results states are clear.
- User-controlled values are escaped in web output.

## Validation notes

- Add command, service, endpoint, renderer, and MCP parity tests.
- Run .NET build and tests.
