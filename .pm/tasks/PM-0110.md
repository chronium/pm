## Goal

Make Overview a project-scoped read-only workspace mode in live and embedded Angular clients.

## Implement

- Add a typed Overview API store and routed page with one page-level loading state, ready composition, actionable invalid state, and localized retryable transport failure.
- Add current `/overview` and linked `/projects/:projectId/overview` routes.
- Keep live and embedded root routes Tasks-first.
- Show Overview in fixed Overview/Tasks/Wiki navigation only when the selected document is ready or invalid.
- Redirect disabled Overview routes to that project's Tasks root.
- Retain Overview while switching projects only when the target exposes it; otherwise land on the target Tasks route.
- Use site title for the Overview document title without changing operational project identity.
- Preserve linked-project context in task and wiki links and keep read-only indication owned by the shell.

## Acceptance

Angular unit and E2E coverage exercises current and linked ready, disabled, invalid, loading, failure, project switching, deep links, document titles, keyboard navigation, and live/embedded Tasks-first behavior.
