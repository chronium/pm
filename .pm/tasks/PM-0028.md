## Goal

Bring `update_task_metadata` parity to CLI for structured task metadata edits without replacing the full markdown file.

## Proposed implementation

- Add `pm task update <id>` with options for `--title`, `--track`, `--milestone`, `--clear-milestone`, and optionally `--description` or `--edit-description`.
- Use `TaskService.PatchTaskMetadata`.
- Keep full-file editing in `pm task edit` unchanged.
- Print whether the task changed or already matched the requested metadata.

## Acceptance criteria

- CLI can update title, track, milestone, and description through structured options.
- Invalid track/milestone/title failures match service errors.
- Clearing a milestone is explicit and does not conflict with omitted milestone.
- MCP `update_task_metadata` behavior remains unchanged.

## Validation notes

- Add command tests for each metadata field, unchanged updates, invalid values, and missing task.
- Run .NET build and tests.
