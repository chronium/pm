## Goal

Bring wiki search parity to CLI so users can search page path, title, and body without MCP or web.

## Proposed implementation

- Add `pm wiki search <query> [--limit]`.
- Reuse `WikiService.SearchPages`.
- Render path, title, modified timestamp, match count, and snippet in a compact table.
- Return stable validation failures for blank query and invalid wiki markdown.

## Acceptance criteria

- CLI returns matching nested wiki pages.
- Blank query fails clearly.
- Snippets are visible and escaped for console output.
- MCP `search_wiki_pages` behavior remains unchanged.

## Validation notes

- Add command behavior tests for matches, no matches, blank query, and invalid markdown.
- Run .NET build and tests.
