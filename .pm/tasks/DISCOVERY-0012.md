## Goal

Establish the shared visual grammar for an opinionated project Overview without changing production routes.

## Prototype

- Build an isolated Storybook or component-gallery composition using realistic project fixtures.
- Present project identity, optional description, Overview/Tasks/Wiki navigation context, and restrained primary links.
- Reuse PM surfaces, typography, accent tokens, buttons, and responsive conventions.
- Keep the result closer to a repository README plus lightweight project dashboard than a marketing page.
- Cover configured and fallback title/description states, light and dark themes, keyboard focus, and mobile layout.

## Deliverable

A reviewable shell and hero prototype that establishes the page hierarchy for subsequent sections.
