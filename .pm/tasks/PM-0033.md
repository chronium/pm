## Goal

Create a CLI analog for the planned `patch_wiki_page` MCP workflow without adding risky web body patch controls.

## Proposed implementation

- After wiki patch service exists, add `pm wiki patch <path>` with options matching supported patch operations.
- Support narrow operations such as replace section, append after heading, and expected-text replacement.
- Use the same service as MCP.
- Keep full-file editing in `pm wiki edit` unchanged.

## Acceptance criteria

- CLI can apply supported narrow wiki patches.
- Missing or ambiguous targets fail without mutation.
- Invalid operation combinations fail clearly.
- Web remains full-page/body editor only for this slice.

## Validation notes

- Add command and service tests for each supported operation and failure mode.
- Run .NET build and tests.
