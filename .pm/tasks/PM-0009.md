## Implementation Plan

- Add a small read-only recent activity surface for recently modified tasks and wiki pages.
- Use existing ModifiedAt metadata rather than changing storage.
- Keep the view lightweight, likely in mode-specific sidebars or index areas.
- Reuse existing timestamp formatting and template patterns where available.

## Acceptance Criteria

- Users can see recently modified tasks and/or wiki pages from an appropriate web UI surface.
- Items are ordered by most recent modification time.
- Empty states are handled without visual noise.
- The feature does not add mutation controls or storage changes.

## Validation Notes

- Test ordering, empty state, mixed task/wiki visibility decisions, and timestamp formatting.
- Run the .NET build and test suite.
