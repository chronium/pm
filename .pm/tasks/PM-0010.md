## Implementation Plan

- When opening the new task flow from a filtered board view, preselect the current track and/or milestone.
- Preserve existing status behavior unless task creation already supports status context.
- Keep the New task action contextual through the existing hidden filter inputs and htmx request patterns.
- Validate stale or invalid filters through existing service-side checks.

## Acceptance Criteria

- Filtered board views prefill matching track and milestone values in the create form.
- Unfiltered board views keep the current default create behavior.
- Invalid stale filter values do not create invalid tasks or break the form.
- Successful creation returns the user to the expected board context.

## Validation Notes

- Test filtered and unfiltered create forms, invalid stale filters, and successful task creation.
- Run the .NET build and test suite.
