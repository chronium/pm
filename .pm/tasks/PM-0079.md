Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Build and validate the directed milestone and trigger activation graph independently from ordinary task dependencies.

Acceptance criteria:
- Add milestone-to-trigger consumption edges.
- Add trigger-to-milestone edges for milestone requirements.
- Add trigger-to-milestone edges for task requirements whose tasks are milestone-assigned.
- Unassigned task requirements add no activation edge.
- Reject direct and indirect cycles with deterministic structured diagnostics.
- Do not mix ordinary task dependency edges into this hard-cycle graph.
- Reuse the existing validator style and add focused DFS regression tests.
