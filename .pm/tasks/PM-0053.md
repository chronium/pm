## Goal

Keep the Angular UI trustworthy while CLI and MCP agents modify the same project.

## Implementation

- Add a small reusable polling coordinator used by feature stores, not a central global state store.
- Poll only the active routed resource approximately every five seconds, send `If-None-Match`, and pause while the document is hidden.
- Cancel obsolete requests when filters/routes change and avoid overlapping polls.
- Auto-refresh pristine board/page/settings views after a revision change.
- When an editor/form is dirty, preserve the local draft and show a clear external-change banner instead of replacing input.
- Block stale saves through the existing `If-Match` contract and present `412` with actions to reload/discard or retain the local draft for manual reapplication.
- Refresh active resources immediately after successful local mutations rather than waiting for the poll.
- Do not add SSE, filesystem watchers, optimistic writes, or cross-process locking.

## Acceptance

- MCP/CLI changes appear in pristine active views without a full-page reload.
- Dirty task/wiki/settings forms are never silently overwritten.
- Hidden tabs stop polling and resume with an immediate conditional refresh.
- Tests cover visibility, cancellation, 304, external revision, dirty-form, and 412 behavior.
