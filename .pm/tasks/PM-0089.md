Follow the Milestone Deliverables and Activation Triggers architecture wiki entry.

Add MCP read and mutation contracts for structured milestones, resolved triggers, trigger definition management, activation transitions, delivery, reopening, and reconciliation.

Acceptance criteria:
- Read payloads keep activation provenance separate from current requirement status.
- Mutation receipts reread through the same authoritative resolver used by read tools.
- Control-plane mutations are available only to trusted MCP capability profiles.
- Isolated run workers cannot activate, override, reset, redefine, deliver, reopen, or reconcile.
- Structured errors and warnings preserve stable codes.
- MCP integration tests cover capability denial and mutation/read consistency.
